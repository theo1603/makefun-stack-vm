A complete interpreter for make.fun's tiny stack ISA: wrapping 32-bit
arithmetic, all ten traps with their exact exit codes, and the step and output
limits. Deterministic, dependency-free, no network.

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
